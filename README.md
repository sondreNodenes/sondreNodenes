### Hi, I'm Sondre 👋
I study Digital Infrastructure and Cybersecurity at NTNU, alongside Economics with a data science profile. This fall I'm on exchange at Shanghai Jiao Tong University.
In summer 2026 I was a DevOps intern at Pexip, where I built a streaming service in Go, ran it on Kubernetes in GCP with Terraform, and set up its CI/CD pipeline in GitHub Actions.

**Current focus:** Go, cloud and Kubernetes, security, and data science. Rust is next.

**Also:** teaching assistant in infrastructure and cloud courses at NTNU, and previous tech lead at [BRAIN NTNU](https://brainntnu.no/), a student organization for AI.
